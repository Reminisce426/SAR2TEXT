# 开源引用、许可与数据使用清单

本清单用于管理第三方代码、模型、权重、数据集、文献、图表和工具。当前仅定义核验流程，不对 OpenCLIP、SAR-CLIP、SAR-TEXT 或 Sentinel-1 GRD 的具体许可状态作未经来源核查的断言。

## 引入前检查

每个第三方项目必须在 [`../../templates/opensource_inventory.csv`](../../templates/opensource_inventory.csv) 中登记，并完成以下字段：

- 唯一名称、用途与类型；
- 官方来源 URL 与固定版本（release、commit、DOI、数据版本或产品版本）；
- 许可证名称和许可证文件 URL；
- 是否允许研究使用、修改、衍生、再分发和商业使用；
- 是否要求署名、保留版权声明、公开修改或采用相同许可证；
- 权重许可是否与代码许可分离；
- 数据条款是否与下载页面说明分离；
- 论文引用、软件引用和数据引用是否齐全；
- 本项目实际修改了什么，哪些文件来自上游；
- 核验人、核验日期和证据快照位置。

## 风险等级

| 等级 | 判定 | 处理 |
|---|---|---|
| 低 | 官方来源、版本和许可明确，使用方式在许可范围内 | 登记后使用 |
| 中 | 权重、数据或衍生物条款与代码许可不同，或再分发边界不清 | 不打包原始资产，仅提供获取脚本与说明；提交前复核 |
| 高 | 无明确许可、来源不明、条款冲突或禁止当前用途 | 暂停使用，替换来源或取得明确授权 |

## 引用原则

1. 学术思想引用论文；代码复用引用仓库和固定版本；数据使用引用数据来源和版本。
2. “参考过”不等于“复现过”；“复现过”必须有本地配置、日志与结果记录。
3. OpenCLIP、SAR-CLIP、SAR-TEXT 仅可标为第三方基线或参考，不能写成本项目创新。
4. 修改第三方代码时记录原路径、修改文件和差异；不要删除上游版权与许可声明。
5. 最终代码包内的 `THIRD_PARTY_NOTICES` 应由已核验清单生成；未核验项不得标成已合规。

## 提交前检查

- [ ] 所有第三方项均有官方来源和固定版本。
- [ ] 代码、权重、数据分别检查许可，不用代码许可替代权重或数据条款。
- [ ] 不允许再分发的资产未被打入提交包。
- [ ] README、论文参考文献和第三方声明中的名称与版本一致。
- [ ] 图表、示例图和截图有来源或为本项目生成。
- [ ] 所有“改进自某方法”的描述能定位到上游方法与本地差异。
- [ ] 许可判断由具名成员和日期确认；有疑义时标为“待核验”。
